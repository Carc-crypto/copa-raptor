COPA RAPTOR 2026 - SITIO WEB

1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server (recomendado) o directamente en el navegador.
3. La imagen del logo está en:
   assets/copa-raptor-2026.jpeg

ARCHIVOS:
- index.html   -> estructura de la página
- style.css    -> diseño visual
- script.js    -> comportamiento del formulario
- assets/      -> imágenes

IMPORTANTE:
El formulario actualmente funciona en el navegador y muestra una confirmación, pero NO guarda
los participantes en una base de datos. Para registrar participantes realmente se necesita
un backend o un servicio de formularios/base de datos.

El diseño usa una paleta azul oscuro + dorado inspirada en el logo de Copa Raptor.
